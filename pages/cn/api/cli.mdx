从仓库根目录运行命令，先激活虚拟环境。用 `ultrarag <command> --help` 查看当前安装版本的参数。

## Build

```bash
ultrarag build examples/experiments/sayhello.yaml --no-mcp --log_level info
```

生成流程目录下的 `parameter/<name>_parameter.yaml` 和 `server/<name>_server.yaml`。修改工具注册或流程后重新 Build。

## Run

```bash
ultrarag run examples/experiments/sayhello.yaml --no-mcp --log_level info
# Optional overrides:
# --param <parameter.yaml> --is_demo
```

`--no-mcp` 在进程内调用本地服务器；默认模式使用 MCP 传输，需安装 `uv sync --extra mcp`。远程 MCP 条目即使在本地模式也需要 MCP extra 和 Node.js 20 以上。日志级别可选 `debug`、`info`、`warn`、`error`。

## UI

```bash
ultrarag show ui --host 127.0.0.1 --port 5050 --no-mcp
```

打开 `http://127.0.0.1:5050`。搭建器编辑和助手工具需要管理员账号。UI 子命令没有 `--admin` 或 `--log_level` 参数；启动前可通过 `log_level` 环境变量配置日志。见 [UI 快速开始](/pages/cn/ui/start)。

## Case study

```bash
ultrarag show case --config_path output/memory_<run>.json --host 127.0.0.1 --port 8080
```
