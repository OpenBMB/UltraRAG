Use `ToolCall` for one registered tool and `PipelineCall` for a complete pipeline. Run these examples from the repository root; sayhello requires no external model.

## ToolCall

```python
from ultrarag.api import ToolCall, initialize, shutdown

initialize(["sayhello"], server_root="servers", no_mcp=True)
try:
    result = ToolCall.sayhello.greet(name="UltraRAG")
    print(result)
finally:
    shutdown()
```

Pass keyword arguments, or expand a dictionary with `**parameters`. Missing arguments are filled from the server parameter file. Initialization is process-wide; finish active calls and release resources before reconfiguring services or leaving the process.

## Async ToolCall

```python
import asyncio
from ultrarag.api import ToolCall, initialize, shutdown

async def main():
    initialize(["sayhello"], server_root="servers", no_mcp=True)
    try:
        result = await ToolCall.sayhello.greet(name="Async UltraRAG")
        print(result)
    finally:
        await shutdown()

asyncio.run(main())
```

## PipelineCall

Generate the parameter and server configuration first:

```bash
ultrarag build examples/experiments/sayhello.yaml --no-mcp
```

```python
from ultrarag.api import PipelineCall

result = PipelineCall(
    pipeline_file="examples/experiments/sayhello.yaml",
    parameter_file="examples/experiments/parameter/sayhello_parameter.yaml",
    no_mcp=True,
    log_level="info",
)
print(result)
```

Inside a running async event loop, use `await PipelineCall(...)`. `PipelineCall` owns the execution client for that run. Omitting `no_mcp=True` uses the default MCP transport and requires the `mcp` extra; mixed remote MCP entries also require it in local mode.
