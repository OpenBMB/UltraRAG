Run from the repository root with the virtual environment activated. Use `ultrarag <command> --help` to check the installed version.

## Build

```bash
ultrarag build examples/experiments/sayhello.yaml --no-mcp --log_level info
```

Generates `parameter/<name>_parameter.yaml` and `server/<name>_server.yaml` beside the pipeline. Rebuild after changing registrations or pipeline steps.

## Run

```bash
ultrarag run examples/experiments/sayhello.yaml --no-mcp --log_level info
# Optional overrides:
# --param <parameter.yaml> --is_demo
```

`--no-mcp` calls local registrations in process. The default transport uses MCP and requires `uv sync --extra mcp`. Remote MCP entries require the MCP extra and Node.js 20 or newer even in local mode. Log levels are `debug`, `info`, `warn` and `error`.

## UI

```bash
ultrarag show ui --host 127.0.0.1 --port 5050 --no-mcp
```

Open `http://127.0.0.1:5050`. Builder edits and assistant tools require an administrator account. The UI subcommand has no `--admin` or `--log_level` argument; configure the `log_level` environment variable before launch. See [UI Quick Start](/pages/en/ui/start).
